Kaiden Flux 0.3.4 - known limits

The Attack Shark/X11 control UI and HID enumeration backend are removed from the compiled application. The manual setup wizard and original signed acceleration driver remain.

AI can tune supported native curve controls and suggest game sensitivity, but cannot program hardware, edit protected device assignments, install/replace drivers, edit LUT point tables, modify a game's settings or guarantee a perfect curve. Recommendations require review and explicit Apply. Separate X/Y parameters take effect only with component calculation enabled. Natural acceleration limits are restricted above 1 in the manual editor.

Gemini requires internet, a valid key and an available model for the user's project. Live Gemini access and recommendation quality have not been account-tested. Automated provider tests use mocked responses. API keys are saved encrypted with Windows DPAPI for the current account; they are not portable to another account. Local memory is bounded JSON. Up to five relevant stored summaries may be sent to Gemini when memory is enabled. Off and Clear are available.

No privileged installation, reboot-persistence cycle or live acceleration-driver application was performed by the tests. The signed SYS payload remains unchanged. The historical HID tests are source-only regression fixtures; they do not mean the removed app integration is present.

Aim tests use windowed WPF pointer coordinates in DIP and high-resolution timing. These are practice comparisons, not raw-input FPS gameplay or controlled causal benchmarks. Interrupted tests are excluded from coaching comparisons. Missing measurements are not fabricated.

Game yaw constants are community references. Verify turn distance in-game; acceleration makes sensitivity speed-dependent. ADS values are stored as context without unverified ADS conversions. The app edits the first/default acceleration profile and preserves device-specific assignments.

Keep the previous desktop version as a fallback. Existing local records are retained at their prior application-data paths. Setup recovery reports errors and shows defaults; review values before saving after a recovery notice.
